# VB6 changes to mirror in Kotlin

While both versions are maintained (PLAN.md §10), every VB6 **code** change on `master`
gets an entry here when `master` is merged into the `kotlin` branch. An entry is closed by a
Kotlin change *plus* a test that covers it.

Changes up to and including `0c57d69` (the branch point) are already in the VB6 source being
ported, so they don't need entries.
